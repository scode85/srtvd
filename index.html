Nối SRT - tải file & tự tính khoảng nghỉ

Tải nhiều file .srt lên (hoặc kéo thả). Hệ thống hiện đúng số ô theo thứ tự file. Bạn có thể tự động tính khoảng nghỉ theo tổng thời gian mục tiêu, hoặc chỉnh thủ công từng đoạn.

Kéo thả file .srt vào đây hoặc chọn file Hỗ trợ nhiều file cùng lúc - sắp xếp theo thứ tự bạn chọn
